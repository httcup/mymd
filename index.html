    手机上打开

    手机扫一下就在手机上打开同一页。配好 GitHub Token 后笔记会自动双向同步，手机电脑看到的是同一份。

    ⚙️ GitHub 同步设置

    生成方法：GitHub → Settings → Developer settings → Fine-grained tokens， 只授权 仓库、权限勾选 Contents: Read and write。 配好后笔记自动双向同步；没配也不影响本地使用。

    本地自动保存

    笔记写进浏览器的本地存储，每敲一句都在存，关掉再开还在。没有账号，清理浏览器站点数据前记得「备份 JSON」或确认已同步到 GitHub。

    一键同步到 GitHub

    在 ⚙️ 里填入你自己的 Fine-grained Token（只授权这一个仓库），笔记就会以明文 .md 存进你仓库的 notes/ 目录，双向同步、自带版本历史；换设备、手机扫码打开都是同一份。

    打开就是 .md

    导出的就是纯文本 Markdown，不夹带样式和内嵌数据。Obsidian、Typora、VS Code、GitHub 都能直接打开，也能再导入回来接着改。
