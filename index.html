    欢迎使用 MYMD 👋

    笔记以明文 Markdown 保存在你的 GitHub 仓库 的 notes/ 目录里。

    左侧选择一篇笔记，或点右上角「＋ 新笔记」开始写。

    ⚠️ 保存到 GitHub 需要先在设置里填入你的 Personal Access Token（仅保存在本机浏览器）。

    ⚙️ 设置

    生成方法：GitHub → Settings → Developer settings → Fine-grained tokens， 只授权 MYMD 这一个仓库，权限勾选 Contents: Read and write。
