# 欢迎使用 MYMD

这是我的第一篇笔记，保存在 GitHub 仓库里。

## 功能速览

- **临时密码门**：每次打开网页需要输入密码，关掉标签页即失效
- **多篇笔记**：左侧列表切换，右上角「＋ 新笔记」创建
- **自动保存**：停止输入 2 秒后自动提交到 GitHub，也可 `Ctrl/Cmd + S` 手动保存
- **Markdown 预览**：编辑器右上角切换预览
- **版本历史**：每次保存都是一个 GitHub commit，可在仓库的 History 里查看/回滚

## 常用语法

**粗体**、*斜体*、`行内代码`

> 引用块
