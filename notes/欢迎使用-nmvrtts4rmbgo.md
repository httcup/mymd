# 欢迎，这是一块本地记事板

左边写，右边就是最终的样子。每敲一句都会自动存在这台设备的浏览器里，关掉页面再回来还在。

## 可以这么用

- [ ] 记待办，导出 .md 丢进仓库
- [ ] 写草稿，写完再粘到别处
- [x] 试试顶栏的「下载 .md」

## 语法速查

| 想要 | 写法 |
| --- | --- |
| 标题 | `# 一级标题` |
| 粗体 | `**粗体**` |
| 列表 | `- 项目` |
| 引用 | `> 引用` |
| 链接 | `[名字](https://example.com)` |

> 「下载 .md」把当前这本存成文件，「备份全部」把所有笔记合成一份。
